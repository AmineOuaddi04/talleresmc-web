# Talleres MC — concepto web

Web estática para Talleres MC (Logroño). La información de servicios y contacto procede de su web pública. Las imágenes de la galería y fachada son fotografías reales de su web; la imagen editorial de la cabecera es generada y no representa sus instalaciones.

## Desarrollo local

Sirve la carpeta con un servidor HTTP estático, por ejemplo `npx serve .` o `node preview.cjs`, y abre la dirección indicada por el servidor.

## Publicación

El proyecto está preparado para GitHub Pages desde la raíz de la rama `main`. Todas las rutas de recursos son relativas.
